# Risk register

| Risk | Control | Owner in pilot |
|---|---|---|
| Quality / contamination | Existing validated procedure remains authoritative; human release only | Quality lead |
| Missing or invalid sensor | Return insufficient-data status; fall back | Operations lead |
| Optimizer causes operational harm | Advisory mode; retain baseline when objective is not improved | Planning lead |
| Misstated impact | Source, assumption and claim audits; common baseline ledger | Sustainability lead |
| Unvalidated reuse | Screening only; site approval required | Water / EHS lead |
| Data / OT cybersecurity | Segmented target architecture, RBAC, audit retention and review | IT/OT lead |
| Model drift | Monitor errors and override rate; deactivate recommendation | Data owner |
