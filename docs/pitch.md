# Pitch

## 30 seconds

L’Oréal publicly reports a 2030 ambition to use recycled or reused water for industrial purposes in its factories. ClearLoop explores an upstream question: can better changeover decisions reduce modeled cleaning-water demand before it enters that loop? In a synthetic, auditable demonstration, it connects production sequencing, governed process signals and conservative reuse screening. It never replaces validated cleaning or water-quality decisions.

## 90 seconds

Start with the fixed-order synthetic baseline. ClearLoop ranks a batch sequence using transparent transition-burden rules and retains the baseline whenever its heuristic cannot improve the configured objective. Next, it simulates cleaning signals. A normal stream can produce an endpoint recommendation, while missing or drifted sensor data produces an insufficient-data fallback and requires the existing validated procedure. Finally, it screens a recovered stream for potential reuse but never approves use. The impact ledger uses one common baseline and reports cascade potential separately to prevent double counting. The next step is a one-line, advisory pilot with comparable metering, quality governance and explicit stop conditions.

## Claim discipline

Every modeled operational value is synthetic or illustrative. Public L’Oréal context is cited in `source_register.md`. Actual water performance, savings, reuse suitability, economics and deployment readiness require plant data and validation.
