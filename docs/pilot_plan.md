# Six-week pilot architecture — not connected to L’Oréal systems

## Scope

One line, a limited and quality-approved product-transition set, advisory mode only. Existing validated procedures remain the execution authority.

## Measurement plan

Capture batch order, changeover start/stop, metered water, quality release outcome, operator override reason, sensor availability and recovered-stream disposition. Retain a fixed-order baseline and an optimized advisory scenario with comparable conditions.

## Success criteria

- No unacceptable quality deviation or safety violation.
- Deadline compliance and operational acceptance.
- Measurable reduction relative to a defined, comparable baseline.
- Adequate data availability and documented operator override rate.
- No reuse path accepted without site-specific validation.

## Stop conditions

Unexpected quality deviation; sensor failure; confidence below plant-approved threshold; contamination concern; unvalidated reuse route; critical system error; or production risk. The fallback is the existing validated procedure.
