# Roadmap after the competition

| Stage | Objective | Evidence required | Exit condition |
|---|---|---|---|
| Now — prototype | Demonstrate mechanism and governance | Synthetic tests, source register, audit trail | Reviewable demonstration |
| Next — data discovery | Define a representative pilot boundary | Meter plan, batch history, validated procedures, data owners | Data quality accepted |
| Then — shadow mode | Compare recommendations against existing plan | Comparable baseline and operator feedback | No unacceptable operational issue |
| Then — controlled pilot | Validate selected transitions in advisory mode | Quality outcomes, water meter, override reasons | Success and stop criteria met |
| Then — integration | Connect approved interfaces | IT/OT architecture, security and change review | Controlled deployment approval |
| Then — scale | Reuse configuration and evidence at more lines | Site-by-site validation | Governance approves expansion |

Target integration architecture is not connected to L’Oréal systems.
